# Bike Rental Shop

A command-line bike rental system built in Bash using PostgreSQL. Users can rent and return bikes interactively via terminal input.

## Features

- View available bikes and rent by ID
- Return rented bikes using phone number lookup
- Tracks customer rentals and updates bike availability
- Uses PostgreSQL for database management

## Tech Stack

- Bash scripting
- PostgreSQL (`psql` CLI)
- freeCodeCamp database configuration
