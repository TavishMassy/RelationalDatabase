# 🧮 Build Five Programs — Bash Scripting Course (FreeCodeCamp RDB)

This repository showcases a completed version of the **“Build Five Programs”** course from [freeCodeCamp’s Relational Database curriculum](https://www.freecodecamp.org/learn/relational-database/learn-bash-scripting-by-building-five-programs/build-five-programs). The project involves creating five standalone Bash scripts, each designed to demonstrate key terminal commands and scripting logic within a virtual Linux environment.

## 🛠️ What’s Included

- `bingo.sh` – A randomized bingo generator
- `countdown.sh` – A timed countdown script using loop logic
- `five.sh` – Custom shell interaction and input processing
- `fortune.sh` – A fortune teller script with string handling
- `questionnaire.sh` – Interactive input with validation and branching
- `.freeCodeCamp` – Metadata and tutorial tracking via CodeRoad
- `.vscode` & `.gitignore` – Dev container setup and workspace config

## 💡 Key Concepts Practiced

- Writing interactive Bash scripts using `echo`, `read`, `if`, and `while`
- Handling conditional logic and user input
- Utilizing arrays, functions, and built-in utilities
- Automating scripts within a Dockerized development container
- Running structured tasks through the CodeRoad interface

## 🚀 Getting Started

To replicate or run this project, follow the [setup instructions](https://www.freecodecamp.org/learn/relational-database/learn-bash-scripting-by-building-five-programs/build-five-programs) provided in the official course. You’ll need:
- Docker Engine
- Visual Studio Code + Dev Containers Extension
- Git

Once you clone the RDB Alpha repo and open it in VS Code:
1. Paste your freeCodeCamp token in the `Dockerfile` under `CODEROAD_WEBHOOK_TOKEN`.
2. Open the command palette and run **Dev Containers: Rebuild and Reopen in Container**.
3. After build, run **CodeRoad: Start** from the command palette.
4. Load the tutorial via URL and begin the course.

Make this an accessible sandbox for learners eager to sharpen their Bash scripting skills through practical, bite-sized programs. Feel free to fork the repo and customize the scripts to fit your learning journey!
