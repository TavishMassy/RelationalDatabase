# Salon Appointment Scheduler
This Bash script allows users to book appointments at a salon via a PostgreSQL database.

## Features
- View available salon services
- Choose a service by ID
- Enter customer phone and name
- Schedule appointment time
- Automatically adds new customers to the database

##  Technologies
- Bash scripting
- PostgreSQL
- Docker
