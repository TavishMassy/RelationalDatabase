# 🎓 Student Database — Part 1 (FreeCodeCamp RDB Course)

This repository contains a completed version of the **“Build a Student Database: Part 1”** course from [freeCodeCamp's Relational Database curriculum](https://www.freecodecamp.org/learn/relational-database/learn-sql-by-building-a-student-database-part-1/build-a-student-database-part-1). It demonstrates how to manage and interact with a PostgreSQL student database using **SQL** and **Bash scripting** within a Dockerized dev container.

## 🛠️ What’s Included

- `students.sql` – SQL schema defining the student database structure
- `courses.csv` & `students.csv` – Sample datasets for batch imports
- `insert_data.sh` – Bash script to populate the database with CSV data
- `.freeCodeCamp` – Progress tracking and metadata files from CodeRoad
- `.vscode` & `.gitignore` – Configuration and environment setup files

## 💡 Key Concepts Practiced

- Creating relational databases and tables in PostgreSQL
- Writing Bash scripts for automated data entry
- Importing structured data from CSV files
- Using Docker and Dev Containers with VS Code
- Following tutorial tasks inside the CodeRoad interface

## 🚀 Getting Started

To replicate or run this project, follow the [setup instructions](https://www.freecodecamp.org/learn/relational-database/learn-sql-by-building-a-student-database-part-1/build-a-student-database-part-1) in the official course. You’ll need:
- Docker Engine
- Visual Studio Code + Dev Containers Extension
- Git

Once you clone the RDB Alpha repo and load the CodeRoad tutorial, paste your token inside the `Dockerfile` to track your progress. Then start developing within the VS Code container.

## ✅ Goal

Make this a friendly and ready-to-use resource for learners who are exploring the fundamentals of SQL databases and automation with Bash. Feel free to fork or clone the repo and build on it!
