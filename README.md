# Celestial Bodies Database 

This Celestial Bodies Database project from freeCodeCamp will guide you through creating a structured PostgreSQL schema representing galaxies, stars, planets, and moons. You can apply concepts like foreign key relationships, hierarchical data modeling, and SQL querying — all using your local PostgreSQL setup on VS code.
